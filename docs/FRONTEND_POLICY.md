# Alpha frontend policy

This client displays synthetic fixture posts and actions confirmed within the current tab. The same local record supplies participant lanes, search and following. Search and Saved locally are personal views, not protocol decisions. There is no live public feed, room presence or keystroke broadcast.

Selected images and videos remain local previews. No upload endpoint, remote media fetch, automatic filename caption or protocol attachment is implemented. Removing a preview changes this tab; it does not delete the original or another host's copy. Future public media handling needs explicit publication consent, metadata decisions, storage terms, retention and a missing-content state.

The intended frontend will make its own display and hosted-media rules understandable. Users should be able to choose another compatible frontend. An operator may stop its own service or hosting; that cannot become a universal protocol ban, balance seizure or deletion authority. The actual mechanism and independent recovery tests remain unfinished.

NFT-controlled pseudonyms remain the manifesto identity target. Imageboard styling does not mean accountless posting or anonymity. Public activity and eventual account ownership can be linkable. This alpha neither collects private correspondence nor supplies encryption.

The website, browser application and future protocol are separate components. GitHub controls this source hosting; the developer controls this unpublished website copy. Neither fact proves that a future deployed protocol is independent of those parties. See RESILIENCE_PLAN.md for proposed failure tests.
