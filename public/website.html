02 / PRINCIPLES

Requirements.
Then proof.

The manifesto and recovered R2 set requirements to prove. Publishing code does not prove them.

  1. / 01

    More than one entrance.

    Portable clients, alternate hosts and usable records. A domain cannot be the only way in.

  2. / 02

    No exclusive switch.

    R2 rejects developer backdoors, proxies and multisigs. Code, dependencies and deployed authority still need independent review.

  3. / 03

    Recover the actual record.

    Restore accounts, actions and required content. A hash alone cannot supply a missing file.

Availability, storage and funding can fail. CAW activity is pseudonymous and can still be linked.
